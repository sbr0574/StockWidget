# StockWidget

简洁的桌面行情显示工具，用透明浮窗查看自选行情，也可在 Windows 任务栏中显示。支持股票、基金、全球主要指数和上期所期货，兼容 **Windows、macOS 和 Linux**。

## 下载与使用

前往 [Releases 下载](https://github.com/sbr0574/StockWidget/releases)，选择适合系统的发布包。

| 平台 | 发布包 | 使用方式 |
| --- | --- | --- |
| Windows 10 / 11 | `StockWidget-Windows-<版本号>.zip` | 解压后运行 `StockWidget.exe` |
| macOS | `StockWidget-macOS-<版本号>.zip` | 解压后将 `StockWidget.app` 拷贝到“应用程序”并运行 |
| Linux | `StockWidget-Linux-<版本号>.zip` | 解压后在该文件夹的终端运行 `./StockWidget`；也可选择 `.deb` 或 `.rpm` 安装包 |

1. 从托盘菜单打开“设置”，在“自选列表”中添加并勾选需要显示的标的。
2. 在“数据”中选择显示指标，拖动调整指标顺序；在“浮窗”中调整颜色、字体和透明度。
3. 按住浮窗任意区域拖动，双击隐藏；通过托盘菜单或已启用的快捷键恢复。
4. 自选较多时，在“浮窗”中开启行数限制、翻页或分栏。Windows 用户也可在“任务栏”中启用任务栏显示。

## 功能

### 自选与行情指标

支持沪、深、京、港、美等市场的股票、基金，以及指数和上期所期货。添加时可按类别、地区筛选；搜索支持代码、名称、拼音、缩写和空格分隔的多个关键词。

- 双击自选列表空白处快速添加，双击已有条目编辑；可拖动调整自选顺序。
- 内置市场代码列表并自动检查更新。
- 指标可自由选择和排序：名称、现价、涨跌、涨幅、浮盈、买一 / 卖一数量、委比、成交量、成交额、均价、当日日 K 线。
- “可用指标”固定显示全部选项，拖动或双击可添加到下方的“已显示指标”；已经显示的选项变灰。拖动已显示指标调整顺序，双击或拖回目录移除，任务栏页采用相同操作。
- 买一 / 卖一在同一列显示，围绕中间方向符号对齐：现价等于买一时显示「◀」，等于卖一时显示「▶」；其他情况及竞价阶段保留同宽空位。两侧保留各自颜色，数量超过 10000 时显示为两位小数的「万」。
- 在“数据 → 指标显示”中直接设置表头、名称、显示字数、市场与代码，以及成交量和成交额单位，浮窗与任务栏共用这些设置。
- 现价触及当日最高或最低时显示 `↑` / `↓`。
- 显示表头后，单击现价、涨跌、涨幅、浮盈、委比、成交量、成交额或均价，按“降序 → 升序 → 不排序”循环；右键菜单也可设置。排序时浮窗会显示名称，取消后恢复原自选顺序。

### 行情图表

在“数据”中开启“点击行情行显示图表”（默认关闭），单击浮窗或任务栏的一行即可打开该标的图表。可切换当日分时、5日分时和最近30个交易日的日K线；日K线可分别开关 MA5、MA10、MA20、MA30、MA60，鼠标移入图表可查看数值。

开关下方的“图表显示方式”可选择“独立窗口”（默认）或“半透明浮窗”。半透明浮窗较小，显示在行情浮窗旁；从任务栏打开时靠近点击位置，屏幕边缘会自动调整位置，小屏幕下会缩小尺寸。点击图表外部、按 `Esc` 或点击右上角关闭按钮即可关闭；图表内仍可切换视图、均线和刷新。关闭图表开关会保留选择的显示方式。

图表跟随当前行情数据源，必要时使用备用源并显示实际来源。历史数据会在本地缓存，交易期间自动检查更新；断网时可继续查看已缓存数据，并提示更新失败。数据均为未复权，休市时分时显示最近可用交易日。

部分海外指数或期货的分钟历史可能不可用或不足5日，图表会明确提示；新上市标的历史不足时，均线从满足周期的位置开始显示。关闭此开关后，点击行情行不再打开图表；拖动、双击隐藏保持原有操作。

### 浮窗外观与操作

透明无框浮窗支持拖动、双击隐藏、右键快捷设置和鼠标穿透。浮窗大小会随数据内容及时调整。

右键菜单中的“退出”可直接结束程序并保存设置。

浮窗和托盘右键菜单提供分栏、鼠标穿透和 Windows 任务栏行情开关；托盘菜单还可打开使用帮助和问题反馈页面。

- 在“浮窗”中设置背景、文字、上涨、下跌和中性颜色，以及背景不透明度、窗口不透明度、字体、字号和行距。
- “统一颜色”默认开启，全部内容使用文字颜色；关闭后显示各自的涨跌颜色。
- 支持表头和网格；在“常规”中选择跟随系统、浅色或深色模式，也可选择内置图标或自定义图标。
- “浮窗 → 浮窗置顶”默认开启。取消后允许其他窗口遮盖，同时关闭“强制置顶”。Windows 可进一步开启强制置顶，鼠标穿透期间也能保持置顶。
- 可开启开机启动；托盘菜单提供显示 / 隐藏、设置和退出操作。

全局快捷键需在“快捷键”中启用，也可自定义组合；注册结果会显示在设置中。

| 默认快捷键 | 操作 |
| --- | --- |
| `Ctrl+Alt+F` | 显示 / 隐藏行情组件 |
| `Ctrl+Alt+C` | 开启 / 关闭鼠标穿透 |

### 行数限制、翻页与分栏

在“浮窗”中勾选“限制行数”，设置每栏最多显示 **1–20 行**。开启其中的“翻页”开关可手动翻页，关闭后只显示前 N 行并收起翻页选项；勾选“自动翻页”后，可在“间隔：”数字框中设置 **1–60 秒**。关闭行数限制后显示全部标的，原设置会保留。

手动翻页使用数据左侧的上箭头、页码和下箭头，首尾循环。分页控件在翻页时保持大小，页码使用行情字体和字号；末页条目不足时仍保留设定行数的高度。分页区域也能拖动浮窗，拖动不会误触翻页。行情刷新保留当前页，修改自选或排序后回到第一页。

勾选“分栏”可将当前页标的均分为左右两栏，前半在左，后半在右；数量为奇数时左栏多一个。可选择是否显示分隔线。行数限制按每栏计算，例如设为 3 行时，两栏一页最多显示 6 个标的。

### Windows 任务栏显示

在“设置 → 任务栏”打开“任务栏行情模式”，立即显示任务栏行情并展开后续设置。浮窗和托盘右键菜单中的“任务栏行情”与这一开关同步。

- 每栏可显示 **1–4 行**，支持不翻页、手动翻页和自动翻页，可调整间隔及向左偏移。
- 指标数量不限，选择和排序方式与浮窗相同。
- 页面顶部的“隐藏托盘图标”默认关闭，开启后隐藏程序的托盘图标，可通过行情右键菜单或已启用的快捷键操作程序。
- 指标、外观、翻页和分栏可分别同步浮窗；取消对应同步后可独立设置，之前的独立设置会保留。
- 外观可独立调整字体、字号、文字颜色、不透明度和统一颜色。打开“自动文字颜色”后，系统深色模式使用白色、浅色模式使用黑色，暂时停用手动颜色和统一颜色选项。任务栏背景透明，过宽内容会省略显示。
- 最大字号随行数、任务栏高度和显示缩放调整，行数较多时上限降低；原字号偏好会保留，减少行数后可恢复更大的显示字号。
- 每组内的同步开关开启时收起独立设置，关闭后恢复已保存的设置；外观组中的偏移量始终可调。
- 两处采用相同的行情排序，分别记录页码；同步翻页时，浮窗关闭行数限制，任务栏也停止翻页。
- 默认只显示一处：将浮窗拖入任务栏时只显示任务栏预览，移出后恢复浮窗，松开即可停靠；按住任务栏行情拖出则恢复浮窗，拖动中按 `Esc` 可取消并恢复。
- 在任务栏显示期间打开“允许浮窗与任务栏同时显示”，可同时显示浮窗；从浮窗拖入任务栏时也可双开。此时任务栏保持显示，浮窗可自由拖过任务栏区域。
- 开启图表后，单击行情行显示图表；双击任一处隐藏整个行情组件，托盘或快捷键在原位置恢复，双开时同步隐藏和显示。
- 总开关关闭时，行情恢复为浮窗且不能拖入任务栏；拖出到浮窗后，总开关仍保持开启。

目前仅支持 Windows 主屏的横向任务栏。任务栏拥挤时可能与图标重叠，可调整偏移；系统更新可能影响显示。任务栏重启后会尝试恢复，显示失败时暂时回到浮窗并重试。

### 自动隐藏

在“常规”中开启“自动隐藏”，可添加最多 **3 个每日时间**，精确到分钟，按电脑本地时间执行；时间列表可完整显示三行，每行右侧可直接删除，顶部说明当前启用情况。关闭总开关会停用定时隐藏与自动识别，并保留设置。

勾选“自动识别”后，当全部勾选标的的行情时间均超过 **30 秒**时隐藏，支持新浪和东方财富；请求失败、缺少行情或缺少时间不会触发。手动呼出后若再次触发，会显示 **5 秒倒计时**；新行情到达、取消自动识别或关闭总开关会取消倒计时。定时规则可同时生效。

这些操作会一起隐藏浮窗与任务栏，呼出时恢复原显示位置。

### 边界检测与贴边收起

两个功能均默认关闭，可在“浮窗”中启用。

- **边界检测**：启动、移动或内容大小变化时自动调整越界位置，保持浮窗在屏幕内；关闭时允许部分浮窗移到屏幕外。
- **贴边收起**：需要先启用边界检测。浮窗贴住屏幕左、上或右边时缩为 **5px 窄条**；鼠标移入展开，移出再次收起，底边不触发。
- 仅浮窗显示时，贴边收起会暂停行情刷新，展开后恢复；双开时任务栏仍显示则继续更新。

## 设置分类

设置窗口通过左侧图标和文字切换分类，窗口大小固定，右侧以单栏显示设置内容，可纵向滚动。常用功能使用开关，标题下方说明作用；快捷键和部分分组总开关保留复选框。颜色选择单独成行，按钮显示圆形预览和带“#”的六位色号。页面滚动时，滑块和下拉框不会因滚轮操作改变设置。

“清空自选列表”位于自选列表页首行最右；“恢复默认外观”和“恢复默认设置”位于常规页底部。

| 页面 | 内容 |
| --- | --- |
| 自选列表 | 添加、编辑、勾选、删除和排序标的 |
| 数据 | 数据源、刷新间隔、图表开关与显示方式、指标显示、名称和单位 |
| 常规 | 颜色模式、图标、开机启动、自动隐藏与恢复默认 |
| 快捷键 | 全局快捷键与注册状态 |
| 浮窗 | 颜色、不透明度、字体、字号、行距、网格、置顶、鼠标穿透、边界、行数、翻页与分栏 |
| 任务栏（仅 Windows） | 托盘图标、启用、双开、行数、偏移及各项同步 / 独立设置 |
| 关于 | 版本、更新与项目信息 |

## 常见问题

**隐藏后如何恢复？**

使用托盘菜单的显示 / 隐藏操作，或已启用的 `Ctrl+Alt+F`。恢复时保留原显示位置，双开时一起恢复。

**启用鼠标穿透后无法点击浮窗怎么办？**

从托盘菜单关闭鼠标穿透，或使用已启用的 `Ctrl+Alt+C`。

**浮窗被任务栏或其他窗口盖住怎么办？**

先检查“浮窗置顶”是否开启。Windows 可再开启“强制置顶”；开启后也可能覆盖截图工具等其他置顶窗口，可按需关闭。

**为什么部分选项不可用？**

功能支持情况因系统而异。任务栏显示与强制置顶仅支持 Windows；macOS 不支持鼠标穿透和图标切换，Linux 部分桌面环境不支持全局快捷键、鼠标穿透或窗口不透明度。以设置中的可用选项和提示为准。

**行情无法刷新怎么办？**

查看浮窗显示的具体错误，检查网络或已有代理设置，也可在“数据”页切换数据源。不同数据源支持的市场和可用情况可能不同。

## 数据说明

行情来自 **新浪财经**或**东方财富**，可能存在延迟、缺失或暂时不可用，仅供参考。程序只显示行情，不包含任何账户或交易操作。

整个行情组件隐藏后暂停刷新和自动翻页，显示后恢复；仍在任务栏显示时继续更新。
