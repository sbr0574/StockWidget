# StockWidget

简洁的桌面行情显示工具，用透明浮窗查看自选行情，也可在 Windows 任务栏中显示。支持股票、基金、全球主要指数和上期所期货，兼容 **Windows、macOS 和 Linux**。

## 下载与使用

前往 [Releases 下载](https://github.com/sbr0574/StockWidget/releases)，选择适合系统的发布包。请使用官方仓库发布的文件。

| 平台与处理器 | 系统版本要求 | ZIP 发布包 |
| --- | --- | --- |
| Windows，Intel / AMD 64位 | Windows 10 1809及以上，或 Windows 11 | `StockWidget-Windows-amd64.zip` |
| Windows，ARM64 | Windows 11 ARM64 | `StockWidget-Windows-arm64.zip` |
| macOS，Intel | macOS 13 Ventura及以上 | `StockWidget-macOS-amd64.zip` |
| macOS，Apple Silicon（M系列） | macOS 13 Ventura及以上 | `StockWidget-macOS-arm64.zip` |
| Linux，Intel / AMD 64位 | Ubuntu 22.04及以上，或提供 glibc 2.35及以上的同类发行版 | `StockWidget-Linux-amd64.zip` |
| Linux，ARM64 | Ubuntu 24.04及以上，或提供 glibc 2.39及以上的同类发行版 | `StockWidget-Linux-arm64.zip` |

`amd64`、`x64`、`x86_64` 指同一种架构；`arm64` 是另一种架构，请同时匹配操作系统和处理器类型。

- Windows：解压后运行 `StockWidget.exe`，或在桌面和开始菜单创建快捷链接启动。
- macOS：解压后将 `StockWidget.app` 拷贝到“应用程序”并运行。
- Linux：解压后在该文件夹的终端运行 `./StockWidget`；两种架构同时提供同名的 `.deb`、`.rpm` 安装包，例如 `StockWidget-Linux-arm64.deb`。安装包会检查对应的 glibc 最低版本。

**若设备未在上表中支持，可尝试下载源码使用**，需要 python 3.12 以上版本：

先安装所需依赖：`pip install -r requirements.txt`

然后编译资源文件：`pyside6-rcc resources/resources.qrc -o resources/resources_rc.py`

最后直接运行 `python main.py` 或打包使用 `pyinstaller --clean --noconfirm StockWidget.spec`

**Windows**：首次运行可能出现“Windows 已保护你的电脑”，这是 SmartScreen 对尚未建立信誉的下载程序的提示。确认文件来自上方官方 Releases 且你信任该程序后，点击“更多信息”→“仍要运行”。如果没有“仍要运行”，可能受 Smart App Control 或组织策略限制，请按系统提示处理；不要为此关闭整个系统的安全保护。可参阅 [Microsoft 的 SmartScreen 说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。

**macOS**：如果提示“无法验证开发者”或“Apple 无法检查 App 是否包含恶意软件”，先尝试打开一次，再进入“系统设置”→“隐私与安全性”，向下找到 StockWidget 的拦截提示，点击“仍要打开”，按提示确认。旧版 macOS 对应“系统偏好设置”→“安全性与隐私”。这只为该 App 添加例外，后续可正常双击打开。具体步骤见 [Apple 的打开 App 说明](https://support.apple.com/zh-cn/102445)。若提示 App 已损坏或将损坏电脑，先从官方 Releases 重新下载，仍有问题时提交反馈并附上系统版本和提示内容。

### 开始使用

1. 从托盘菜单打开“设置”，在“自选列表”中添加并勾选需要显示的标的。
2. 在“数据”中选择显示指标，拖动调整顺序；在“外观”中调整颜色、字体和透明度。
3. 按住浮窗任意区域拖动，双击隐藏；通过托盘菜单或已启用的快捷键恢复。
4. 自选较多时，开启行数限制、翻页或分栏。Windows 用户还可在“任务栏”中启用任务栏显示。

## 功能

### 自选与行情指标

支持沪、深、京、港、美等市场的股票、基金，以及指数和上期所期货。添加时可按类别、地区筛选；搜索支持代码、名称、拼音、缩写和空格分隔的多个关键词。

- 双击自选列表空白处快速添加，双击已有条目编辑；拖动调整自选顺序。
- 内置市场代码列表并自动检查更新。
- 可选指标：名称、现价、涨跌、涨幅、浮盈、买一 / 卖一数量、委比、成交量、成交额、均值、量比、迷你图。均值可在“数据 → 指标设置 → 均值指标”选择当日均值或 MA5 / 10 / 20 / 30 / 60；缺少所需历史时显示空值。
- 拖动或双击“可用指标”添加；拖动“已显示指标”调整顺序，双击或拖回目录移除。
- 在“数据 → 指标显示”添加、移除或排序指标，以及开关表头；名称字数、代码、类型和成交单位在“指标设置”中调整。名称字数可选择不显示、完整显示或前 1–4 个字。
- 现价触及当日最高或最低时显示 `↑` / `↓`。
- 单击数值表头按“降序 → 升序 → 不排序”循环，右键菜单也可排序；取消后恢复原自选顺序。

在“数据 → 指标设置 → 迷你图”点击日 K 线、走势或幅值图的预览按钮选择样式。走势图以五分钟粒度展示当日价格与灰色零轴，末段随最新行情更新；整条走势线使用同一种颜色，非统一颜色模式下按当前价格相对昨收选择上涨、下跌或中性色。幅值图用横线表示当日最低至最高涨幅，小圆点表示当前涨幅。同一页、同一分栏共用幅值范围，便于比较不同标的；包含零涨幅时显示贯穿各行的灰色零轴。走势和幅值图固定占 10 个数字字符的宽度，线条粗细跟随字体，并沿用所在浮窗或任务栏的统一颜色设置。

### 行情图表

图表浮窗默认同步主浮窗的背景和整体不透明度，可在“外观 → 不透明度”关闭同步后分别调整。外观页滑块在松开鼠标后生效。

默认可单击浮窗或任务栏的一行查看行情图表；可在“数据 → 行情数据”关闭“点击显示行情图表”。支持当日分时、5日分时和最近30个交易日的日K线。鼠标移入图表显示十字虚线和坐标轴读数，图下固定显示对应数据，移开后恢复最新一条。分时与5日图仅用一行显示均价、价格及涨跌幅、成交量；日K第一行显示开、高、低、收、成交量，下一行显示已开启的MA值。小窗口自动适配数据栏字号。当日分时使用4×4网格，五日分时按交易日分列并居中显示日期，悬停时横轴显示对应日期和时间。

图表浮窗靠近行情显示，可拖拽标题调整位置，拖拽边缘或四角调整大小，按 `Esc` 可取消正在进行的拖动或缩放。分时、5日、日K共用最小尺寸和一份浮窗尺寸记录；五档开关统一影响三个视图的最小尺寸，切换视图和行情刷新保留当前大小与位置。窗口限制在当前屏幕可用范围内。未固定时点击外部可关闭；点击大头针按钮可固定浮窗，固定后点击外部保持显示。无拖动操作时按 `Esc` 或点击关闭按钮可关闭，隐藏行情时图表随之关闭。点击关闭按钮旁的“↗”可打开独立窗口，原浮窗随即关闭；独立窗口在任务栏显示应用图标，可正常最小化与恢复，单独记住大小。名称旁的上下箭头按已勾选自选的列表顺序循环切换，保留当前图表类型和窗口大小。5日图使用五分钟粒度显示价格与成交量。

独立窗口顶部显示当前报价、涨跌，以及五列开高低昨收、内外盘、成交量额、均价、换手率、振幅、量比、估值与股本数据。估值列依次为静态市盈率、动态市盈率、TTM市盈率、市净率。国内股票市盈率使用当前总市值和对应归母净利润计算，动态口径将最新报告期累计利润年化；股本与财务资料按日保存在本地，盘中估值随现价变化。各市场的字段覆盖不同，数据缺失、口径不能确认或不适用时显示“—”。沪深京股票与基金的量比根据新浪前五个交易日日K和当日已交易时间计算，数据不足时同样显示“—”。量比大于1用上涨色、小于1用下跌色、等于1用中性色，外盘用上涨色，内盘用下跌色。

图表上方左侧切换分时、5日、日K，右侧直接开关“成交量”“均线”“五档”。开启五档后，当日分时图右侧显示卖5至卖1、买卖盘细条、买1至买5；细条左红为买盘、右绿为卖盘，长度按五档总委托量分配。未提供盘口的标的显示空值。切换到日K并开启均线后，下一行显示带对应颜色的 MA5 / 10 / 20 / 30 / 60 开关。

基本行情与图表使用新浪财经，沪深北个股的内外盘统计使用腾讯。内外盘的分类口径、更新时间可能与其他软件不同，两者之和可能小于总成交量。图表跟随行情刷新，并保存在本地以便再次查看；最新分钟的成交量随行情补充，随后按分钟数据校准。指数图表的成交量以历史数据为准。数据均为未复权，休市时显示最近可用交易日。港股分钟历史目前只返回最近一个交易日，本地缓存可逐日积累；全球指数提供日K，分钟历史可能不可用。部分标的历史不足5日时会提示实际天数；历史不足时，均线从满足周期的位置开始显示。

“关于”页底部提供检查程序更新和恢复默认设置；发现新版本时，提示窗附有下载链接。“外观”页标题右侧可恢复默认外观。

### 数据目录与缓存

在“常规 → 数据与缓存目录”更改配置、自选、股票代码列表和图表缓存的保存位置。修改时复制现有数据，重启后使用新目录，原目录保留；目标已有的程序数据会先备份。重启前的图表缓存仍使用原目录。“打开数据目录”打开当前正在使用的位置，“清理数据缓存”清除图表缓存，保留配置、自选和代码列表。

默认位置：Windows 为 `%APPDATA%\StockWidget`，macOS 为 `~/Library/Application Support/StockWidget`，Linux 为 `~/StockWidget`。Windows 默认目录不可写时，自动回退到程序所在文件夹。设置保存失败时会提示尚未保存，可在常规页选择可写目录；仍可打开设置和正常退出。

### 浮窗外观与操作

透明无框浮窗支持全区域拖动、双击隐藏、右键快捷设置和鼠标穿透，大小随行情内容调整。

- 可设置颜色、不透明度、字体、字号、行距、表头和网格；主浮窗及图表浮窗的背景不透明度为1%–100%，整体不透明度为10%–100%。任务栏不透明度为10%–100%。关闭“统一颜色”后显示各自的涨跌颜色。
- “浮窗置顶”默认开启，Windows 可进一步开启“强制置顶”。
- 字体、颜色、不透明度、颜色模式和图标集中在“外观”；窗口行为、分栏和行数限制集中在“常规”。
- 在“外观”选择跟随系统、浅色或深色模式及图标；开机启动位于“常规”。
- 浮窗与任务栏右键菜单可调整指标、排序、网格、统一颜色和分栏，并提供设置与退出入口。任务栏菜单保持紧凑，不提供表头开关。
- 托盘菜单可显示 / 隐藏行情、关闭鼠标穿透、打开帮助或提交问题；Windows 下也可切换任务栏行情。

全局快捷键需在“快捷键”中启用，支持自定义组合，并显示注册结果。

| 默认快捷键 | 操作 |
| --- | --- |
| `Ctrl+Alt+F` | 显示 / 隐藏行情组件 |
| `Ctrl+Alt+C` | 开启 / 关闭鼠标穿透 |

### 翻页与分栏

浮窗可限制每栏 **1–20 行**，选择只显示前 N 行、手动翻页或自动翻页（间隔 **1–60 秒**）。手动翻页使用数据左侧的箭头，首尾循环。关闭行数限制后显示全部标的，原设置保留。

开启分栏后，当前页按顺序分为左右两栏，可选择分隔线。例如每栏限制3行时，一页最多显示6个标的。

### Windows 任务栏显示

在“设置 → 任务栏”开启“任务栏行情模式”，立即切换到任务栏显示。

- 每栏 **1–4 行**，支持翻页、分栏、网格和左右偏移；偏移正值向左、负值向右，向右可能覆盖托盘区域。
- 指标、翻页和分栏可分别同步浮窗，或保留独立设置。
- 任务栏字体类型与统一颜色模式跟随主浮窗，文字大小、文字颜色与不透明度独立设置。默认每栏3行、8pt、不透明度50%，开启“自动文字颜色”，随系统深浅模式切换，也可从任务栏右键菜单切换“自动配色”。文字大小在5–15pt内调整，上限还受任务栏实际高度、行数和缩放限制；增加行数会压缩字号，减少行数后恢复原有字号偏好。
- 单独任务栏模式下，将浮窗拖入任务栏停靠，拖出恢复浮窗；松开确认，`Esc` 取消。开启“允许浮窗与任务栏同时显示”后，任务栏固定不可拖动，浮窗可自由移动，经过任务栏不吸附。
- 可隐藏托盘图标，随后通过行情右键菜单或快捷键操作程序。

支持 Windows 各屏幕的横向任务栏。首次开启时以浮窗所在屏幕为目标，单独任务栏模式可将行情拖到另一屏幕的任务栏；双开时任务栏保持原位置，移动浮窗不会改变其停靠位置。目标屏幕需开启 Windows 的多显示器任务栏。拥挤时可能与图标重叠，可调整偏移；Explorer 重启后会尝试恢复，嵌入失败时暂时回到浮窗并重试。

设置窗口作为普通窗口打开，具有任务栏图标，可最小化，并可被其他普通窗口覆盖；macOS在设置或独立图表窗口显示时提供程序坞图标。设置窗口在浮窗所在屏幕打开；仅显示任务栏行情时，跟随任务栏所在屏幕。

### 自动隐藏与贴边收起

“常规 → 自动隐藏”支持每天最多三个定时隐藏时间，也可在全部行情超过 30 秒未更新时，延迟 5 秒后自动隐藏。

“常规 → 窗口行为 → 保持在屏幕内”允许拖动时自由移出屏幕，松开鼠标后将越界浮窗调整回屏幕内。“贴边收起”可在屏幕四边将浮窗缩为窄条，鼠标移入展开，移出收起；下侧收起会避开任务栏或 Dock。Windows 需先开启“保持在屏幕内”；macOS 和 Linux X11 可直接开启贴边收起。Wayland 下无法可靠手动定位，贴边收起不可用。

行情组件完全隐藏后暂停刷新和翻页，恢复后继续；仅浮窗贴边收起、任务栏仍显示时继续刷新行情。

## 常见问题

**Windows下任务栏遮挡浮窗**

在“常规 → 窗口行为”中开启强制置顶，或打开任务栏行情模式开关，将行情显示固定在任务栏上。

**隐藏或开启鼠标穿透后如何操作？**

通过托盘菜单或已启用的快捷键恢复显示、关闭穿透。关闭托盘图标显示和快捷键时，不建议使用鼠标穿透

**为什么部分设置没有显示或无法使用？**

Linux X11 支持全局快捷键和鼠标穿透，而 Wayland 下这些功能及窗口不透明度不可用。以当前界面的选项和提示为准。

**行情无法刷新怎么办？**

查看浮窗错误提示，检查网络或已有代理设置。新浪支持的市场范围及实时、历史数据可用情况可能不同。反馈问题时请附上系统、程序版本、标的代码和错误提示。
